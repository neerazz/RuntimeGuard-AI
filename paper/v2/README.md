# RuntimeGuard-AI V2 paper

This directory contains the independently authored V2 paper and its reproducible visual sources.

## Build

From this directory:

```bash
python3 generate_diagrams.py
tectonic -X compile runtimeguard-v2.tex --outdir build --keep-logs
```

The release PDF is `runtimeguard-v2.pdf`. It is copied from a clean successful build only after citation, text-extraction, metadata, and page-render checks pass.

## Evidence binding

`generate_results_tex.py` accepts only a completed canonical run and emits `generated-results.tex` from `summary/key_findings.json`. It refuses quick or failed runs. The manuscript imports those macros and references figures generated by `experiments/v2/analyze.py` from manifest-verified raw data.

Conceptual figures are generated by `generate_diagrams.py`; each has PDF and PNG output. No image-generation model is used for diagrams or charts.

The original journal article remains the immutable version of record at DOI `10.5281/zenodo.18527375`. V2 is a successor with corrected claims, implementation, evidence, and metadata; it does not overwrite the archived record.
